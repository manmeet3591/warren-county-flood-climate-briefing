# Data

Open data behind this page. Everything here comes from public sources and may be reused with the attributions below.

- `usgs/03287500_kentucky_river_lock4_frankfort_2025-04_hourly.csv`: hourly gage height (ft, EDT) for the Kentucky River at Lock 4, Frankfort, from USGS instantaneous data (approved). U.S. Geological Survey, Water Data for the Nation (https://waterdata.usgs.gov); public domain.
- `../assets/*.png`: transparent renderings of the NASA/JPL OPERA DSWx-S1 v1.0 water classification layer (B01_WTR) for tile T16SFH on April 6 and April 13, 2025, with county boundaries. Granules: `OPERA_L3_DSWx-S1_T16SFH_20250406T234025Z_20250407T102148Z_S1A_30_v1.0_B01_WTR.tif` and `OPERA_L3_DSWx-S1_T16SFH_20250413T233211Z_20250414T133032Z_S1A_30_v1.0_B01_WTR.tif`. Citation: OPERA Dynamic Surface Water Extent from Sentinel-1 (Version 1), NASA PO.DAAC, doi:10.5067/OPDSWS1-L3V1. Contains modified Copernicus Sentinel data (2025).
- `map_overlays_april_2025.json`: marker positions (fractions of image width and height), the western edge of the April 13 look, the zoom box and map extents.
- `stats_april_2025.json`: acquisition times, tile coverage, stage at each pass and water areas shown on the page.

The full data set for the Kentucky River replay, including the February 2025 records, is in https://github.com/manmeet3591/kentucky-river-flood-replay/tree/main/data.
